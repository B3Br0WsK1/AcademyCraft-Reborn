# AcademyCraft Reborn

Unofficial port of [AcademyCraft](https://github.com/LambdaInnovation/AcademyCraft) 1.1.3 by Lambda Innovation
to **Fabric** for **Minecraft 26.3**.

Become an ESPer: Electromaster, Meltdowner, Teleporter or Vector Manipulator — 35+ skills, the ability developer,
the data terminal, energy machines and imaginary-phase worldgen.

## Requirements

- Minecraft 26.3, Fabric Loader ≥ 0.19.5, Fabric API, Java 25

## Building

```
./gradlew build
```

The jar is written to `build/libs/`.
