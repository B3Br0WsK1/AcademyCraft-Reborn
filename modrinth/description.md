# AcademyCraft Reborn

> **Unofficial** Fabric port of **AcademyCraft 1.1.3** by [Lambda Innovation](https://github.com/LambdaInnovation/AcademyCraft) for Minecraft 26.3.
> Not affiliated with or endorsed by Lambda Innovation.

Inspired by *A Certain Magical Index / A Certain Scientific Railgun*, AcademyCraft lets you become an **ESPer** —
develop a superpower, train it from Level 1 to Level 5 and bend reality around you.

## Features

- **4 ability categories, 35+ skills**
  - ⚡ **Electromaster** — Arc Generation, Railgun (flip a coin!), Iron Sand Control, Magnet Movement, Thunderclap, Thunder Bolt, Body Intensify…
  - ☢ **Meltdowner** — Electron Bomb, Scattering Bomb, Meltdowner, Ray Barrage, Light Shield, Jet Engine, Electron Missile, Mining Rays…
  - 🌀 **Teleporter** — Threatening Teleport, Penetrate Teleport, Mark / Location Teleport, Flesh Ripping, Shift Teleport, Flashing…
  - ➡ **Vector Manipulator** — Vector Acceleration, Directed Shock, Groundshock, Storm Wing, Vector Reflection, Blood Retrograde, Plasma Cannon…
- **Ability Developer** — awaken and level up your ability, learn new skills in the skill tree
- **CP & Overload** system, skill experience, presets with custom key bindings
- **Data Terminal** — a HUD "phone" with apps: Skill Tree, MisakaCloud tutorial, Media Player, Frequency Transmitter, Settings
- **Machines & energy (IF)** — wind/solar/phase generators, matrix & nodes wireless network, metal former, imaginary-phase fusor, energy converters
- **World generation** — imaginary-phase liquid lakes, constraint metal, imag crystal, resonant crystal and imag silicon ores
- Advancements and the in-game MisakaCloud tutorial

## Requirements

- Minecraft **26.3**
- [Fabric Loader](https://fabricmc.net/) ≥ 0.19.5
- [Fabric API](https://modrinth.com/mod/fabric-api)
- Java 25

Install on **both client and server**.

## Getting started

1. Craft or find an **Ability Developer** (portable or block version).
2. Use it to awaken your ability — your category is chosen at random.
3. Press **V** to toggle ability mode, use **mouse buttons / R / F** to cast skills, **C** to switch preset, **N** to edit presets.
4. Learn more skills in the skill tree as you level up. The tutorial app explains the rest.

## Port status

This is a **beta**. Everything from the original has been ported, but bugs are expected — please report them!
Removed compared to the original: anonymous analytics, IC2 / RF / JEI / CraftTweaker integrations.

## 🇷🇺 Русский

**Неофициальный** порт **AcademyCraft 1.1.3** от Lambda Innovation на Fabric для Minecraft 26.3.

Станьте **эспером** в духе «Индекса волшебства / Railgun»: развивайте сверхспособность с 1 до 5 уровня.

- 4 категории и 35+ навыков: **Электромастер** (в т.ч. Рейлган), **Мелтдаунер**, **Телепортер**, **Векторный манипулятор**

- Терминал данных с приложениями, механизмы и беспроводная энергосеть, генерация мира (озёра мнимой фазы, руды)
